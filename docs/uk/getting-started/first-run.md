# Перший запуск

> **Тип контенту**: Task — запуск GoFLE та відкриття першого лог файлу.
> **Аудиторія**: Усі користувачі
> **Передумови**: [Встановлення завершено](install-docker.md) — бінарник доступний як `./GoFLE` або `build/bin/GoFLE`
> **Verified**: 2026-10-29 — протестовано на Linux, macOS, Windows

## Призначення

Запустити GoFLE вперше та відкрити лог файл через GUI або командний рядок.

## Процедура

### Варіант 1: Запуск GUI та відкриття файлу

1. Запустіть GoFLE:
   ```bash
   ./GoFLE
   # або
   ./build/bin/GoFLE
   ```

2. Головне вікно відкривається з порожнім станом, що показує:
   - "Відкрийте лог, щоб почати"
   - Зону для drag-and-drop
   - Панель інструментів з Open, Recent, Remote, Go to Line, Help, Settings

3. Відкрийте лог файл:
   - **Drag and drop** `.log` або `.txt` файл на вікно, АБО
   - Натисніть `Ctrl+O` та виберіть один або декілька файлів, АБО
   - Натисніть кнопку **Open** на панелі інструментів (іконка теки)

4. Файл відкривається в новій вкладці. Індекс зміщень рядків будується миттєво (показує "Індексація..." на короткий час). Контент логу з'являється в верхній панелі.

### Варіант 2: Відкриття файлу з командного рядка

```bash
# Відкрити один або декілька файлів напряму
./GoFLE /var/log/syslog /home/user/app.log

# Відкрити віддалений файл через SSH
./GoFLE ssh://user@host:22/var/log/nginx/access.log

# Відкрити віддалений файл через FTP
./GoFLE ftp://user@host:21/path/to/log.txt
```

Кожен аргумент відкривається в окремій вкладці.

### Варіант 3: Web UI режим

```bash
# Запустити HTTP сервер на порту 8080
./GoFLE -web

# Власний порт
./GoFLE -web :9090
```

Відкрийте `http://localhost:8080/` в браузері. UI ідентичний десктопному додатку.

## Очікуваний результат

- GoFLE вікно відкривається (або вкладка браузера для `-web`)
- Вибрані файл(и) завантажуються в вкладки
- Статус бар показує ім'я файлу, розмір, кількість рядків
- Кнопка Follow показує "Tail: ACTIVE" (нові рядки з'являються автоматично)

## Перевірка

1. Відкрийте відомий лог файл (наприклад, `/var/log/syslog` або будь-який `.log` файл)
2. Підтвердьте, що рядки логу з'являються в верхній панелі
3. Введіть пошуковий термін в поле пошуку (нижня панель інструментів)
4. Натисніть `Enter` — результати з'являються в нижній панелі
5. Натисніть `F` — follow перемикається (статус бар змінюється)

## Вирішення проблем

| Симптом | Причина | Рішення |
|---------|---------|---------|
| Вікно відкривається, але порожнє | Файл не відкрито | Використовуйте `Ctrl+O` або перетягніть файл |
| "Failed to open file" | Немає прав на читання | Перевірте права на читання файлу |
| Бінарник падає при старті | Відсутні системні бібліотеки (Linux) | Встановіть передумови з [Передумов](prerequisites.md) |
| `-web` порт вже зайнятий | Порт 8080 зайнятий | Використовуйте `-web :9090` для іншого порту |
