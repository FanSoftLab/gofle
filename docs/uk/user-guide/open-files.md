# Відкрити файли

> **Тип контенту**: Task — відкрити локальні лог файли в GoFLE.
> **Аудиторія**: Усі користувачі
> **Передумови**: [Перший запуск](first-run.md) завершено — GoFLE запущено
> **Verified**: 2026-10-29 — протестовано на Linux, macOS, Windows

## Призначення

Відкрити один або декілька локальних лог файлів через GUI, командний рядок, drag-and-drop, або асоціації файлів.

## Передумови

- GoFLE встановлено та запущено
- Доступ на читання до цільових лог файлів
- Розмір файлу: будь-який (тестовано до 10+ GB)

## Процедура

### Метод 1: Кнопка Open на панелі інструментів

1. Натисніть кнопку **Open** (іконка теки) на панелі інструментів, АБО натисніть `Ctrl+O`.
2. У діалозі вибору файлу оберіть один або декілька файлів.
3. Натисніть **Open**.
4. Кожен файл відкривається в новій вкладці.

### Метод 2: Drag and Drop

1. Перетягніть лог файл з вашого файлового менеджера.
2. Відпустіть його на вікні GoFLE.
3. Файл відкривається в новій вкладці.

### Метод 3: Аргументи командного рядка

```bash
# Один файл
./GoFLE /var/log/syslog

# Декілька файлів
./GoFLE /var/log/syslog /var/log/auth.log /home/user/app.log

# З вже запущеним GUI
# Файли відкриваються в нових вкладках в існуючому екземплярі
```

### Метод 4: Асоціація файлів (Linux/macOS)

1. Клацніть правою кнопкою на `.log` файл у файловому менеджері.
2. Оберіть **Відкрити за допомогою** → **GoFLE**.
3. Встановіть як типовий, якщо потрібно.

### Метод 5: Нещодавні файли

1. Натисніть кнопку **Recent** (іконка годинника) або натисніть `Ctrl+R`.
2. Оберіть вкладку **Local**.
3. Подвійний клік на файл або виберіть і натисніть **Open**.

## Очікуваний результат

- Нова вкладка створюється для кожного файлу
- Вкладка показує ім'я файлу (скорочене, якщо довге)
- Верхня панель відображає контент логу з номерами рядків
- Статус бар показує: шлях до файлу, розмір, кількість рядків
- Follow режим: "Tail: ACTIVE" (нові рядки з'являються автоматично)

## Перевірка

1. Відкрийте файл з відомим контентом (наприклад, `/var/log/syslog`)
2. Підтвердьте, що перший і останній рядки видимі
3. Прокрутіть — рядки рендеряться плавно
4. Перевірте, що статус бар показує правильну кількість рядків

## Вирішення проблем

| Симптом | Причина | Рішення |
|---------|---------|---------|
| "Permission denied" | Немає доступу на читання | `chmod +r /path/to/file` або `sudo` |
| Файл відкривається, але порожній | Бінарний файл або кодування | GoFLE читає як UTF-8; бінарні файли показують replacement chars |
| Вкладка відкривається і закривається | Файл видалено під час індексації | Переконайтеся, що файл існує і стабільний |
| Drag-and-drop не працює | Wayland/permissions | Використовуйте `Ctrl+O` замість |
