# Документація GoFLE

**Go Fast Log Explorer** — крос-платформовий десктопний переглядач для перегляду, пошуку та слідкування за дуже великими лог-файлами та віддаленими (SSH/FTP) логами.

## Область застосування

GoFLE — це **орієнтований на читання переглядач логів**, розроблений для:

- Відкриття файлів будь-якого розміру (сотні МБ — ГБ) миттєво через індекс зміщень рядків
- Слідкування / follow локальних та віддалених логів
- Паралельний підрядковий/regex пошук з розширеними фільтрами (Nearby — Поруч, Levels — Рівні, Time — Час, Exclude — Виключити, Range — Діапазон, Top — Топ)
- Кілька вкладок з кольоровими групами та відновленням сесії
- Віддалений доступ через SSH та FTP/FTPS (explicit/implicit) з пінгуванням сертифікатів
- Термінальний компаньйон (`gofle`), що повторно використовує той самий Go бекенд

GoFLE **навмисно не є**:

- Лог-агрегатором або колектором (немає ingestion, indexing server, агентів)
- Текстовим редактором (неможливо модифікувати логи — тільки читати, шукати, копіювати, експортувати)
- Парсером/аналізатором структурованих логів (пошук лінійний)

## Огляд архітектури

GoFLE слідує моделі **тонкий бекенд / тонкий фронтенд** (Wails v2):

```
┌─────────────────────────────────────────────────────────────────┐
│  Frontend (TypeScript + Vite)                                   │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐            │
│  │VirtualScroller│ │ TabManager   │ │ Modal/SSH/   │            │
│  │ (rendering)   │ │ (tabs/groups)│ │ ContextMenu  │            │
│  └──────┬───────┘ └──────┬───────┘ └──────┬───────┘            │
└─────────┼────────────────┼────────────────┼────────────────────┘
          │  wailsjs bridge (generated)   │
┌─────────┼────────────────┼────────────────┼────────────────────┐
│  Go Backend (bound to frontend)                              │
│  ┌──────▼───────┐ ┌─────▼───────┐ ┌─────▼───────┐ ┌────────▼──┐│
│  │   app.go     │ │ pkg/indexer │ │ pkg/search  │ │ pkg/ssh   ││
│  │ (App, tabs,  │ │ (offset     │ │ (parallel   │ │ (SSH      ││
│  │  polling,    │──▶│  index,     │──▶│  regex/     │ │  streamer)││
│  │  orchestr.)  │ │  tail)      │ │  substring) │ │           ││
│  └──────────────┘ └─────────────┘ └─────────────┘ └───────────┘│
│         │                │                │                      │
│         └────────────────┴────────────────┘                      │
│                      ┌───────▼────────┐                          │
│                      │  pkg/config    │◄── settings, recent,     │
│                      │ (settings,     │    tabs, AES-GCM secrets │
│                      │  recent, tabs) │                          │
│                      └────────────────┘                          │
└─────────────────────────────────────────────────────────────────┘
```

Ключові пакети:
- `pkg/indexer` — індекс зміщень байтів, `pread` випадковий доступ, інкрементальне слідкування
- `pkg/search` — паралельний worker pool, regex/substring, LRU кеш скомпільованих regex
- `pkg/remote` — спільні інтерфейси `Streamer`/`Lister` (реалізовані в `pkg/ssh`, `pkg/ftp`)
- `pkg/config` — persisted JSON + AES-GCM зашифровані секрети
- `pkg/logging` — централізований `slog` для десктопного бінарника та `gofle` CLI

## Термінологія

Вся документація використовує [глосарій проекту](../glossary.md) для узгодженої двомовної (UK/EN) термінології.

Ключові терміни:
- **follow** / **слідкувати** — live tailing (не "tail", не "хвіст")
- **line-offset index** / **індекс зміщень рядків** — in-memory масив позицій рядків
- **results pane** / **панель результатів** — панель результатів пошуку
- **advanced filters bar** / **панель розширених фільтрів** — рядок фільтр-чіпів
- **search preset** / **пресет пошуку** — збережена комбінація фільтрів
- **tab group** / **група вкладок** — кольорова колекція вкладок
- **config directory** / **директорія конфігурації** — OS-специфічна папка налаштувань
- **terminal viewer** / **термінальний переглядач** — `gofle` CLI інтерактивний переглядач
